# AWS architecture icons

The SVGs in this directory are official AWS architecture service icons, obtained
from the **July 31, 2026** icon package linked from the
[AWS architecture icons page](https://aws.amazon.com/architecture/icons/).

Source archive:
[Icon-package_07312026.zip](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip).

AWS permits customers and partners to use these assets to create architecture
diagrams. The icons and related marks belong to Amazon Web Services; they are
not covered by this project's license and do not imply AWS endorsement.
Consult the source page for AWS's usage guidance.

Atlas uses the original colored service artwork without recoloring or distortion.
The supported subset is embedded as SVG data URLs in `assets/engine.html` so
generated atlases work offline and do not request third-party images.
An icon is shown only when a node explicitly declares a supported `aws` service
identifier and the viewer enables AWS icons. Component shape is a separate field.
